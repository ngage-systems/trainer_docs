# Basic operation

1. Turn on the main power switch.  
2. Fill the water bottle with the desired reward liquid and place it in the smart bottle holder.  
3. Feed the juice line into the bottle so it reaches the bottom, then screw on the top.  
4. Use the **Purge** button so the juice line fills and operates correctly (see [Using the Juicer](juicer.md)).  
5. Using a computer or tablet, [connect to the device](ess-control-quick-start.md), load the task, and confirm everything works before mounting.  
6. [Attach the trainer to the cage](cage-mounting.md) using the hooks and clamps.  
7. On the main screen, identify the main regions (screenshot with labels TODO).  
8. Create or choose a project.  
9. Create or choose a task (`?` — confirm workflow with your lab).  
10. Decide whether to save data and proceed accordingly.  
11. Start the task.  
12. Repeat as needed.  
13. Remove the trainer from the cage.  
14. Wipe down the trainer, especially the screen.  
15. Rinse the bottle, fill with soapy water or an alkaline cleaner such as **Five Star PBW Liquid**, purge, then purge with clean water.  
16. Place the trainer on the charger.  

It is recommended to leave the trainer **charging and powered on** when not in use.
